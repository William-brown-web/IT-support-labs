# Freshdesk Help Desk Simulation

## Objective

To understand how support tickets are created, managed, prioritised and resolved using Freshdesk.

## Tools Used

- Freshdesk
- Google Chrome

## Skills Demonstrated

- Ticket Management
- Customer Support
- SLA Awareness
- Prioritisation
- Documentation

## Activities Completed

- Created tickets
- Assigned ticket priorities
- Updated ticket status
- Responded to customers
- Closed resolved tickets

## Lessons Learned

Freshdesk helps IT teams organise customer requests efficiently while ensuring no issue is overlooked.
